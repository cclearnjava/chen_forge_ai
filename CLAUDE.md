## Project Overview

ChenForge AI 是一个面向 ToB 企业老板的一人 AI 落地咨询与软件交付门户。项目目标是在一周 MVP 内跑通：

```text
公开官网 -> 线索提交 -> 后端保存 -> 私有后台查看 -> Agent 诊断 -> 人工审批 -> PoC Proposal 草稿
```

核心定位：

- 不是通用 AI SaaS。
- 不是纯展示 Demo。
- 是“人类专家负责，Agent 团队提效”的 AI 咨询交付操作系统雏形。

当前技术路线：

- 前端：Next.js + TypeScript，当前已有静态 HTML/CSS/JS 原型。
- 后端：FastAPI + SQLAlchemy。
- 数据库：SQLite，本地 MVP 使用；领域模型保持 Postgres 迁移友好。
- Agent：先实现轻量自定义 workflow runner 和确定性 mock LLM provider，再接 OpenAI-compatible provider。
- 部署：MVP 锁定前端 Vercel、后端 Render。

Rules:
- Never fix guardian issues directly on `main` — use a dedicated branch
- Close only after verification is recorded with evidence
