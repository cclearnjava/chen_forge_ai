# ChenForge AI

ChenForge AI 是一个由人主导的 AI 落地咨询与软件交付工作室概念，面向希望真正落地 AI Agent 的企业老板和业务负责人。

第一版是一个静态网站，重点是搭建公开公司门户：品牌定位、服务内容、落地方法、交付保障和线索提交入口。

## 本地打开

直接用浏览器打开 `index.html`。

当前 MVP 不需要安装依赖。

## 当前 Demo 展示内容

- 面向 AI Agent / 软件咨询工作室的公开首页。
- 面向 ToB 老板的 AI 落地痛点与服务定位。
- ChenForge 方法论：诊断、设计、构建、验证、运营。
- 带人工审批边界的 Agent 团队展示。
- 线索提交表单，并在页面内生成初步诊断摘要。

## 下一步实现方向

- 增加真实后端，保存线索、任务、决策和生成物。
- 接入 LLM provider，让 Agent 工作流生成诊断、Proposal、PRD 和交付计划。
- 增加带认证的私有运营后台。
- 从客户提交的业务问题自动生成可审核的咨询交付材料。
